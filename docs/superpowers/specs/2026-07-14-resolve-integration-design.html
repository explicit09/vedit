Vedit inside Resolve

No Terminal. No file picker. OTIO stays behind the curtain.

Target: Resolve Studio 20.1+

The V1 loop

1 · OpenWorkspace → Workflow Integrations → Vedit
2 · SnapshotResolve exports the active timeline silently
3 · CommitExisting Vedit engine versions the edit locally
4 · ReviewHistory and semantic changes appear immediately

Thin adapter architecture

  • Resolve promise API handles project, timeline, and export.
  • Sandboxed renderer talks through a narrow preload bridge.
  • Bundled CLI sidecar owns commits, diffs, and history.
  • Blackmagic's native module is copied from the installed SDK.
